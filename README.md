##  Project Description
Campus Connect Hub is a simple educational web platform designed to help students share learning resources, view announcements, and collaborate with classmates.  
It uses HTML, CSS, and JavaScript with LocalStorage to store data directly in the browser.

---

##  Purpose of the Project
The purpose of this project is to:
- Improve collaboration among students
- Allow sharing of academic resources
- Provide a simple announcement system
- Practice frontend web development skills

---

##  Technologies Used
- HTML5  
- CSS3  
- JavaScript 
- LocalStorage API  

---

## Features
- Add and view study resources  
- Post announcements  
- Edit and delete announcements  
- Responsive navigation bar  
- Clean and simple UI

## How to Run
1. Download or clone the project: https://github.com/peshky38-sketch/campus-connect-hub
2. Open folder in VS Code  
3. Open `index.html` in browser  
4. Start using the system
